# 真涨薪微信小程序

七个独立的本地决策工具：Offer 收入与时间对比、租房通勤成本、空窗期预算、学习投入、消费选择、换城市生活、副业尝试；另有日常打卡板块，记录喝水、睡眠与运动。无需登录，数据保存在本机。

本地已接入新页面；微信正式上线状态见 `docs/life-decision-development-status.md`。AppID、正式名称与图标不变。

支持通过微信右上角菜单或结果页按钮分享工具入口。入口及达成分享使用固定图片，不截取个人结果；不携带金额、自定义名称，好友使用自己的本机草稿。生活周刊默认不分享个人数值；可明确开启记录选项，生成并确认预览后分享汇总图片，链接不携带记录。

## 微信开发者工具导入

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本目录。
3. 当前 `project.config.json` 已配置小程序 AppID `wxd183b2cabea63847`；如导入其他账号的小程序，请先替换为对应 AppID。
4. 编译后默认进入「日常」Tab 的「三件小事」，用晨间回顾、日间喝水和夜间收尾引导行动；三环按需展开。从「决策」Tab 选择七个计算场景。Offer 保留原输入、结果和反超流程；旧分享链接仍直接进入 Offer。

## 新场景

- 三件小事：大水可设常用杯后一键记录，其他容量与撤销按需展开；薄肌区分训练/恢复安排，力量训练按周去重统计训练日，原场次和分钟数保留，旧次数目标需重新确认天数；大睡区分睡前准备与醒来后的实际小时数，感受可选。支持补记、7 天回顾、自定目标、复制 JSON 留存及独立清除。目标默认不设，不输出健康评分。
- 运动明细支持直接修改类型和时长，保存后原位替换，不重复新增；可取消修改，保存失败时保留输入供重试。周统计、回顾与达成展示同步刷新，切换日期或跨日时退出编辑，避免错记。
- 生活周刊：自然周真实记录汇总，可选封面心情；默认无个人数值，开启记录选项后先生成预览，再主动分享图片。预览失败可重试，变更选项后旧图立即失效。没有数据不会虚构成果。
- 当天已设置的每日目标全部达成后，自动弹出庆祝弹框，每天一次；同时展示今日运动分钟、分类型汇总与本周力量训练天数/目标，恢复安排不计为运动。运动按周看，不作为每日庆祝门槛。小屏内容可滚动，分享与关闭动作固定可见；可从进度卡回看并分享静态达成卡片，不携带个人记录。

- 租房通勤：依次填写住处 A、B，比较月支出与通勤时间。没有支出请明确填 0；不自动假定通勤天数，不含搬家、押金等一次性成本。
- 空窗期预算：可用预算 = 当前资金 − 预留 − 一次性支出；按正的月净支出估算覆盖月数。起点缺口优先提示，收支相抵或结余不显示“无限”。
- 学习投入：费用、学习小时与停工收入损失分开输入。按自定目标计算所需月增收；假设月增收可留空，未知不按 0 计算。回本从增收开始算，不含学习和等待期，不预测涨薪。所需月增收向上取整到分，回本时间向上保留一位小数。
- 消费选择：适用于已有仍能满足需求的物品。买、租、继续用按同一周期比较总成本与单次成本，继续用计入当前净值减少；旧买价不重复计入。买或租时假设可处置原物品，残值均为个人假设，不保证可售价格，不把成本较低当作购买建议。
- 换城市生活：比较当前与迁居后的月均到账收入、住房和其他现金支出，展示月结余及其变化。仅在迁居后结余为正且增加时，以增加额估算抵回一次性迁居支出的月数；这是相对留在原地的差额比较，不是实际现金积累速度，也不判断哪座城市更适合你。
- 副业尝试：按单或按次收费，分开前期投入、单次成本、固定月支出和总投入时间。给出覆盖月支出与目标期回收投入所需单量；单量可留空，只有正的假设月经营结余才算回收时间。每小时经营结余不是工资，不预测销量、自动估税或作合规审查。
- 决定前核对：三个场景各四个行动问题，补充真实条件、生活影响与退出安排；原生下拉标记状态，本机分场景保存，不给决策打分。条件变化时可确认开始新一轮，不改计算草稿；分享不含核对状态。主题参考 HowToLiveBetter 固定提交 `5f210ca`，重新编写且保留来源与授权，不移植政策或研究数字。
- 七个场景的草稿独立保存；本场景重填与全量清除均需确认。本机保存失败仍可查看当次结果。
- 来源与隐私页提供公式、参考归属、授权链接和存储边界。没有云同步或服务端。

## 计算口径

- 每年工作 48 周。
- 每年通勤 240 天，按往返计算。
- 五险缴费基数、公积金缴存基数和公司公积金比例为可选项。
- 公司公积金年缴存 = 公积金缴存基数 × 公司比例 × 12，并计入年综合价值。
- 税前保证收入不含个税、个人五险一金扣款、公司公积金、试用期折扣、浮动奖金、股票和期权。
- 年综合价值 = 税前保证年收入 + 公司公积金年缴存。
- 综合时薪 = 年综合价值 ÷（年度工作时间 + 年度通勤时间）。

## 项目结构

- `pages/habits`：默认「日常」Tab，「三件小事」行动首页、按需展开的进度、回顾及节奏设置。
- `pages/journal`：生活周刊、隐私可选的图片生成与分享预览。
- `pages/home`：「决策」Tab，七场景入口及本机草稿状态。
- `pages/decision`、`pages/decision-result`：租房、预算、学习、消费、迁居、副业分步输入、校验、结果与编辑。
- `pages/decision-check`：三场景的决定前核对、独立状态与来源说明。
- `pages/about`：来源、计算口径与隐私说明、全量清除。
- `pages/calculator`：输入、校验、本地草稿与示例数据。
- `pages/result`：年综合价值、税前保证收入、综合时薪、年度占用和通勤的深色对比结果。
- `pages/breakeven`：覆盖全部两两工作组合；拖动奖金月数或每周工时后实时试算，不回写原始数据。
- `utils`：与界面无关的计算、校验、格式化和本地存储逻辑。
- `tests`：计算、边界测试，以及“填示例 → 计算 → 结果 → 反超试算”页面流程测试。
